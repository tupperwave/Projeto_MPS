# Requisitos não funcionais — critérios pendentes

## Purpose

Registrar os requisitos não funcionais fornecidos pela equipe e as pendências para torná-los verificáveis.

## Requirements

Os requisitos abaixo foram copiados do material atual. As descrições não definem metas verificáveis suficientes; a equipe deve acordar medidas e cenários antes de tratá-los como critérios de aceitação.

### Requirement: NF-US-01 (orig. RNF-01) — Usabilidade
A interface TUI deve ser intuitiva e responsiva. Definir tarefas, medida e limite de resposta.

**Prioridade:** não informada
**Casos de uso:** UC01 a UC09

#### Scenario: Critério de usabilidade a definir
- **GIVEN** a equipe ainda não definiu uma medida e limite para usabilidade e responsividade
- **WHEN** a especificação for revisada
- **THEN** os critérios devem ser acordados antes de validar este requisito
