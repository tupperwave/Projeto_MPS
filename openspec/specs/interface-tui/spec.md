# Interface TUI

## Purpose

Definir o acesso aos fluxos documentados por meio da interface de terminal do sistema.

## Requirements

### Requirement: RF10 — Oferecer interface de terminal
O sistema DEVE oferecer navegação por terminal com atalhos e feedback visual.

**Prioridade:** Essencial
**Casos de uso:** UC01 a UC09

#### Scenario: Operar pelo terminal
- **GIVEN** o operador inicia o sistema em um terminal compatível
- **WHEN** navega pelos recursos documentados
- **THEN** os fluxos descritos são acessíveis pela interface de terminal
