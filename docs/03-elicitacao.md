# 3. Elicitação

## Material disponível

O repositório contém casos de uso e listas de requisitos em um arquivo Markdown original, além de um PDF de requisitos anterior. Os arquivos foram preservados em [`anexos/`](03-elicitacao/anexos/). O PDF registra entrevistas, análise de ferramentas e brainstorming em 2024; como esse conteúdo pertence a uma versão anterior do projeto e diverge do material atual, ele não foi assumido como evidência da elicitação atual.

## Situação da elicitação

A equipe informou que não houve elicitação formal para a linha de base atual. Portanto, não há técnicas, datas, participantes ou evidências de sessões a registrar. Os requisitos disponíveis vieram de documentos existentes; eles são fontes documentais, não evidência de entrevistas, questionários ou reuniões de elicitação.

Se a equipe realizar elicitação posteriormente, registrar a técnica, data, contexto, participantes, justificativa, evidências e requisitos resultantes.

## Rastreabilidade

Os casos de uso derivados do arquivo-fonte estão em [`04-casos-de-uso/`](04-casos-de-uso/). Os requisitos funcionais foram organizados por capacidade em [`openspec/specs/`](../openspec/specs/).
