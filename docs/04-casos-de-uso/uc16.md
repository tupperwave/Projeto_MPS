# UC16 — Consultar tentativas e exportar relatório de acessos

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador autorizado |
| **Objetivo** | Consultar estatísticas de tentativas de autenticação por usuário e exportar um relatório |
| **Requisito relacionado** | RF33 |
| **Pré-condições** | Aplicação iniciada e repositório de acessos disponível |

## Fluxo principal — exportar relatório

1. O operador escolhe `html` ou `pdf` e informa o caminho de saída por `relatorio-acessos --formato FORMATO --saida CAMINHO`.
2. O sistema consulta as tentativas de acesso agrupadas por login.
3. O sistema calcula totais, sucessos, falhas e data do último acesso.
4. O sistema gera o relatório no formato escolhido e grava o arquivo no caminho informado.

## Fluxos alternativos

- **Geração por outro cliente:** um cliente da aplicação pode solicitar o formato texto ao `UserAccessReportService`.
- **Nenhum acesso registrado:** o sistema gera o relatório com cabeçalho e sem linhas de usuários.

## Exceções

- Formato inválido é rejeitado. Se o caminho de saída for inacessível, a gravação levanta um erro de entrada/saída e não conclui a exportação.
- Os relatórios não incluem senha, salt ou hash de senha.

## Pós-condições

- As estatísticas refletem as tentativas persistidas no momento da consulta.
- O arquivo HTML ou PDF fica disponível no caminho solicitado.
