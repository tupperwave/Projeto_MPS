## UC12 — Cadastrar host

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador |
| **Objetivo** | Cadastrar um host associado a um usuário responsável |
| **Requisitos relacionados** | RF22, RF20, RF21 |
| **Pré-condições** | O usuário responsável está cadastrado |

### Fluxo principal

1. O operador seleciona o cadastro de host.
2. O sistema solicita IP, hostname e demais dados.
3. O operador informa o usuário responsável.
4. O sistema valida os dados.
5. O sistema verifica a existência do usuário.
6. O sistema salva o host.
7. O sistema informa o sucesso.

### Exceções

- IP inválido.
- Hostname inválido.
- Usuário responsável inexistente.
- Host duplicado.
- Falha de persistência.

### Pós-condições

- O host fica registrado e associado ao usuário responsável.
