## UC10 — Cadastrar usuário

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador autorizado |
| **Objetivo** | Cadastrar um novo usuário no sistema |
| **Requisitos relacionados** | RF16, RF18, RF20, RF21 |
| **Pré-condições** | A aplicação foi inicializada e um mecanismo de persistência foi selecionado |

### Fluxo principal

1. O operador seleciona o cadastro de usuário.
2. O sistema solicita o login.
3. O sistema solicita a senha.
4. O sistema valida o login.
5. O sistema valida a senha.
6. O sistema verifica se o login já existe.
7. O sistema protege a senha antes do armazenamento.
8. O sistema persiste o usuário.
9. O sistema informa o sucesso.

### Exceções

- Login vazio.
- Login com mais de 12 caracteres.
- Login contendo números.
- Senha com menos de 8 caracteres.
- Senha sem letra maiúscula.
- Senha sem letra minúscula.
- Senha sem número.
- Senha sem caractere especial.
- Login duplicado.
- Erro de leitura ou escrita.

### Pós-condições

- O usuário válido é armazenado.
- A senha não é apresentada nem armazenada em texto puro.
