## UC11 — Listar usuários

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador autorizado |
| **Objetivo** | Consultar todos os usuários cadastrados |
| **Requisitos relacionados** | RF16, RF17 |
| **Pré-condições** | A aplicação foi inicializada e o mecanismo de persistência foi selecionado |

### Fluxo principal

1. O operador solicita a listagem pela CLI (`nethub usuarios listar`) ou pela TUI (atalho `u`).
2. O sistema consulta o repositório correspondente ao mecanismo selecionado na inicialização.
3. O sistema apresenta todos os usuários cadastrados.
4. O sistema omite senhas e quaisquer dados de autenticação sensíveis.

### Exceções

- Nenhum usuário cadastrado: o sistema informa que a lista está vazia.
- Falha ao ler a coleção, o arquivo binário ou o banco de dados: o sistema informa a falha sem apresentar a listagem como concluída.

O modo de persistência é selecionado na inicialização com `--persistencia-usuarios memoria|sqlite`; sem a opção, usa memória.

### Pós-condições

- A lista de usuários é apresentada sem expor credenciais.
