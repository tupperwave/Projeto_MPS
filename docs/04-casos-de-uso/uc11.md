## UC11 — Listar usuários

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador autorizado |
| **Objetivo** | Consultar todos os usuários cadastrados |
| **Requisitos relacionados** | RF17, RF20, RF21 |
| **Pré-condições** | A aplicação foi inicializada |

### Fluxo principal

1. O operador seleciona a listagem de usuários.
2. O sistema consulta o repositório.
3. O sistema apresenta os usuários cadastrados.
4. O sistema omite senhas e informações sensíveis.

### Exceções

- Nenhum usuário cadastrado: o sistema informa que a lista está vazia.
- Erro de leitura: o sistema informa a falha.

### Pós-condições

- A lista de usuários é apresentada sem expor credenciais.
