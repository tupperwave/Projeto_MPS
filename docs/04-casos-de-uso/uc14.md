## UC17 — Consultar total de entidades

| Campo | Descrição |
|---|---|
| **Ator principal** | Administrador ou operador |
| **Objetivo** | Consultar a quantidade total de entidades cadastradas |
| **Requisitos relacionados** | RF27, RF28 |
| **Pré-condições** | A fachada Singleton foi inicializada |

### Fluxo principal

1. O operador solicita o resumo do sistema.
2. A fachada consulta a quantidade de usuários.
3. A fachada consulta a quantidade de hosts.
4. A fachada soma os totais.
5. O sistema apresenta os totais e o total geral.
