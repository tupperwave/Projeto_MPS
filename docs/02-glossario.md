# 2. Glossário

| Termo | Definição |
|---|---|
| NetHub | Ferramenta TUI proposta para descoberta, inventário, operação e auditoria de infraestrutura. |
| Terminal-first | Interface principal operada no terminal. |
| TUI | Interface interativa de terminal com navegação por teclado. |
| Agentless | Abordagem sem agente próprio instalado nos hosts; ainda pode depender de ferramentas externas. |
| Operador | Pessoa que define o escopo e utiliza o sistema para consultar ou administrar hosts. |
| Host | Dispositivo identificado na rede. |
| Inventário | Registro de hosts e dados observados, que pode ficar desatualizado. |
| CIDR | Notação que delimita um bloco de endereços IP. |
| Nmap | Ferramenta citada para descoberta de hosts e serviços. |
| SSH | Protocolo de acesso remoto seguro citado para autenticação e execução remota. |
| SFTP | Protocolo de transferência de arquivos sobre SSH. |
| SQLite | Banco relacional local citado para armazenar inventário e registros. |
| Capability | Ação considerada tecnicamente disponível com base em evidências, credenciais e privilégios. |
| Autenticação | Verificação da identidade; não implica autorização irrestrita. |
| Autorização | Permissão para executar uma ação específica sobre um recurso. |
| Risco | Classificação do impacto potencial de uma ação, usada para definir controles e confirmação. |
| Auditoria | Registro consultável de ações, alvos, horários e resultados. |
| Evidência | Dados associados ao resultado de uma ação, como status e código de saída. |
| Dry-run | Simulação que apresenta as etapas sem alterar o alvo. |
| Workflow | Sequência de etapas com pré-condições e política de falha. |
| Validação pós-ação | Verificação do estado do alvo depois de uma operação. |
| Checksum | Valor usado para comparar a integridade de conteúdo transferido. |

**Convenção:** serviço alcançável não significa usuário autenticado nem autorizado. A detecção de `sudo` isoladamente não prova autorização para qualquer ação.
