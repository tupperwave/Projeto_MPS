# Como colaborar

## Documentação

- Edite os documentos da disciplina em `docs/`.
- Mantenha os requisitos vigentes em `openspec/specs/`, com IDs estáveis, prioridade e ao menos um cenário por requisito.
- Registre uma mudança de requisito em `openspec/changes/` antes de incorporá-la à especificação vigente.
- Não substitua os arquivos preservados em `docs/03-elicitacao/anexos/fontes/`; atualize a documentação organizada e registre a origem.
- Use Mermaid para diagramas renderizados pelo GitHub.

## Identificadores

Use RFnn para requisitos funcionais, NF-CAT-nn para não funcionais, UCnn para casos de uso, TLnn para telas e ADR-nnnn para decisões de arquitetura. IDs já publicados não devem ser renumerados ou reutilizados.
